工作区（每区独立任务链 ID）
域结构（每个工作区）：💬 主会话·追随 · 🎨🖌 设计·可独立 fork · 📋📚 审查/知识库·追随 main · ✏️ 编辑器·chat 变种
情境 · 检查器
读法：左边每个工作区自带唯一 ws 编号与自动任务链 ID；中间任务树节点 = 分支任务，标签 = 链上状态；⑂ fork 对面的分支 = 树上声明（来源链/工作区/分支自动携带，链上自动产生 4 条记录）；⇄ 合并 = merge commit 双亲上链 + 谱系回边；📋 审查报告 / 📚 知识库没有独立分支（追随 main）；🎨🖌 设计节点可独立分叉；✏️ 编辑器任务 = chat 任务变种。底部 时间线 = 操作流程级行为轨迹（谁做了什么、到哪一步、是否并入——数据源为链上记录聚合）。右侧所有按钮均可点；点轨迹行可展开链上记录原文。
