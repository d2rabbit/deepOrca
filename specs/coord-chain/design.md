# 工作链 · 设计文档（与设计稿同步）

> 2026-09-07 · 与 screen-workchain.html（真实 DOM 基底交互稿）对应 · 需求基线见 requirements-reset.md

## 设计方向（定稿）

1. 无链模块：不存在「工作链」模块/面板/视图。链是隐藏行为，全部注入现有模块。
2. 任务树 = 核心：整个共享链（本地 + 链历史）的唯一承载。每个节点显示链 id（fork 节点=来源链 id）；底部链操作日志（每个链操作 = 链 id + 操作）。
3. fork = checkout 新分支，树上声明、行为即上链（自动）；来源链/来源设备/分支断言自动携带。merge = cherry-pick（冲突只报告）。
4. 域化落地：会话任务 → 会话模块新会话任务（声明链 id）+ 知识库/审查报告/编辑器自动构建关联版本（代码强绑定）；编辑器 = chat 变种，本地历史快照（VSCode/IDEA 式）上链 = 链上操作历史快照；UI 设计 / 原型设计 = 唯二可独立 fork（本地版本管理上新增链上版本）；审查 / 知识库随代码、不可单独 fork。
5. 设置：真实 SettingsPanel 10 段导航为基底，仅「链共享」段新增单个开关（关=本地独立；开=自动上链）。
6. 链 id：绑定设备、每设备唯一；可见位置=任务树节点、会话任务 item 底部、各模块版本 item 下（=来源链 id）。

## 设计稿结构

- 基底：运行中应用真实 DOM（CDP 提取，real-ui/），实际使用主题 styles-line.css
- 外壳：七模块切换（iframe 承载真实面）
- 注入层：任务树（链 chip/链操作日志/fork·merge pop）· 会话（声明链 id）· 设计/原型（目录链上版本 item）· 审查/知识库（链上版本卡）· 编辑器（链上快照卡）· 设置（真实导航 + 链共享段）

## 验证

Playwright 全流程：七模块切换均含对应链注入元素；任务树 fork/merge、设置开关、节点链 id 行全部生效。
