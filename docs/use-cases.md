## 案例 1：接手陌生代码库

**场景**：你刚 clone 了一个数万行的项目，需要在一小时内说清它的架构、找到核心模块、理清一次典型请求的数据流。

**步骤**：

1. 在 DeepOrca 中打开该工作区，点击左栏 **「索引与知识」**，在工作区行上点 **「构建」**。
   依次执行 符号索引 → Wiki → 架构图 三个阶段，行下方有实时进度，右下角徽标显示后台运行中。
2. 构建完成后，会话输入框上方会弹出 **「Wiki 已更新 · N 页」** 建议条 —— 这是知识与对话的连接点：
   - 点 **「查看」** 直达知识中心；
   - 或点 **「引用到对话」**，输入框自动填入一条基于 `@openwiki/` 的架构分析提问，回车即问。
3. 在知识中心的 **「架构图」** 子页：地图在点阵画布上铺满展示，多张图用顶部胶囊切换，支持缩放与适配宽度。
   节点按 8 色循环着色、子图虚线分框，模块边界一眼可辨。
4. 在 **「Wiki」** 子页阅读项目文档（文档站排版），任何页面可点 **「引用到对话」** 把该页作为上下文带入提问。
5. 在 **「符号」** 子页切换到关系图视图：调用方（紫）｜ 焦点（蓝）｜ 被调用（青）三列，
   点击任意节点即可下钻重定中心，返回按钮可回溯浏览路径。
6. 之后随时按 <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> 输入「知识」即可跳回知识中心。

**产出**：一份可对话的架构理解 —— 而不是三个彼此割裂的工具面板。

## 案例 2：提交前审查闭环

**场景**：一个 feature 分支改了 20 个文件，合并前想快速过一遍质量与结构性风险，个别发现需要和 AI 讨论清楚再决定怎么改。

**步骤**：

1. 左栏 **「代码审查」** → 点 **「审查」**（`review.full`）。OCR 语义审查生成结构化意见；
   若已构建 CRG 图谱，还会附带结构风险标注（如 "HIGH (12 callers)"）。
2. 结果区出现发现列表与两个动作：
   - **💬 在对话中追问** —— 把当前发现（带风险标注，最多 8 条）注入会话输入框，
     你可以补一句「哪几条是必须改的」再发送，与 AI 逐条讨论；
   - **🔧 一键修复** —— 基于发现清单生成修复规划并同步到会话模式执行。
3. 讨论清楚后按建议修改，或直接走一键修复；修复后可再次审查验证收敛。

**产出**：从「发现问题」到「理解问题」到「解决问题」的完整链路，全部在同一个窗口内完成。

## 案例 3：从需求到可交互原型

**场景**：产品提了一个新页面需求，想在写代码前先看到一个可点击的原型，并且基于它继续讨论迭代。

**步骤**：

1. 会话输入 `/prototype`（或描述需求后让 AI 使用原型渲染工具）。
2. 生成的可交互原型在右侧预览区打开 —— 支持真实的页面跳转与表单交互。
3. 在预览区底部的迷你输入框直接描述改动（「把提交按钮改成渐变色」），
   迭代请求直接回到会话执行，原型实时刷新，无需切窗口。
4. 满意后让 AI 按原型实现，原型代码即规格说明。

**产出**：需求 → 原型 → 迭代 → 实现，每一环都留在会话上下文里，AI 始终知道「要做什么、为什么」。

## 案例 4：让 AI 懂你的仓库

**场景**：团队有一套构建规范与代码约定，希望每次会话的 AI 都自动遵守，而不是每次口头重复。

**步骤**：

1. 会话输入 `/init`，AI 扫描仓库后生成 `AGENTS.md`（构建命令、目录约定、测试方式等）。
2. 左栏「索引与知识」→ **「AGENTS」** 子页可直接阅读渲染后的内容；
   点「在编辑器中打开」可手工修订、提交入库。
3. 团队成员 clone 仓库后，DeepOrca 自动读取 `AGENTS.md`，人人共享同一份 AI 协作约定。
4. 配合 Skills 目录（`docs/agent-skills.md`）沉淀更细的团队工作流。

**产出**：把「怎么和 AI 协作」本身纳入版本管理。

| 快捷键                            | 动作                                 |

| <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> | 命令面板（导航、主题、知识中心直达） |

| <kbd>⇧Tab</kbd>                   | 计划模式（先读后写）                 |
| <kbd>⌘?</kbd>                     | 快捷键帮助                           |
