## 三、下阶段优先级建议

按"用户感知价值 × 实现可行性"排序：

### P0 — 立即值得做（已有地基，补全即见效）

#### 1. TDAI 记忆向量召回开关翻转（§二）

**现状**：embedding 基建已通（Granite + sqlite-vec + local-onnx provider），但 `MemoryManager` 默认 `embedding: { enabled: false }`。召回测试已证明向量命中率 100%。

**要做**：在桌面端设置页加「记忆向量召回」开关，翻转后用户对话记忆从 BM25-only 升级为 hybrid（向量+关键词）。零新代码，只是配置暴露。

**价值**：用户立刻感知到"它记住了我之前说的"质变。

#### 2. skill-up CI 评估（§十一，S1）

**现状**：已有 `specs/skill-eval/design.md`，设计完整。内置 7 个插件包 + 用户技能目前没有质量回归。

**要做**：按设计文档 S1 —— 给 7 个插件包加 `evals/` 骨架 + GitHub Actions nightly 跑 skill-up。零产品改动，纯 CI。

**价值**：改技能不再"盲改"，有量化回归报告。

### P1 — 近期值得做（地基已铺，组合即见效）

#### 3. 路由准确率抽查（§十，M2 验收）

**现状**：G1/G2/G3 路由已上线（fail-open 默认开），但没有准确率基准。

**要做**：50 条中文查询 × 现有技能池，测 top-8 命中率（以 flash LLM 分类结果为伪标签）。不达标调 query/passage 前缀或换 bge-base-zh。

**价值**：确认路由不伤准确率，才敢放心开默认。

#### 4. book-to-skill 集成（§十一）

**现状**：路线图已收录，无代码。

**要做**：把 virgiliojr94/book-to-skill（Python）vendor 进来或做成 MCP 工具，让用户输入一本书/文档 → 自动产出 SKILL.md。

**价值**：技能从"手写"升级为"文档生成"，降低技能创作门槛。

#### 5. OpenWiki + arch-scan 联动验证（§一）

**现状**：构建索引三步已接（CodeGraph→Wiki→arch-scan），但没端到端跑过完整流程（需要 desktop 运行时）。

**要做**：启动桌面端，对当前仓库点「构建索引」，确认三步顺序执行 + arch-scan 产出 A2UI Surface 能在预览面板渲染。

**价值**：验证索引三件套真正可用（目前只测了 skill 指令 + Surface 结构，没测 UI 渲染）。

### P2 — 中期值得做

#### 6. 活动帧行为记忆（§二）

activity-frames TS 重写（已有 `specs/archive/activity-frames/design.md`），补齐"做了什么"记忆层。与 TDAM（说了什么）互补。

#### 7. 远程接入（§十三）

WebSocket 桥 + 静态服务，SessionBridge 已 engine-agnostic，可零改造复用。手机/远程浏览器接入。

#### 8. 语音双工（§十四）

whisper.cpp 本地优先 + API 兜底，语音替代键盘输入。

### P3 — 远期

- 桌面自动化（§九）：pi-computer-use / sim-use
- 能力编排协议（§十六）：OpenWork 双工具 MCP
- 密钥保险库（§十七）：OneCLI SQLite 重构
- 统一模型网关（§十五）：OmniRoute

## 五、总结

本轮（v3.16）在 `perf/native-optimizations` 分支完成了**向量嵌入 + 语义路由 + 架构扫描**三大块，共：

- **3 个新 workspace/模块**：`@deeporca/embedding`、`packages/core/src/routing/`、`arch-scan` skill
- **45 个单测**（embedding 8 + routing 30 + arch-scan 结构 60 = 全过）
- **3 个端到端验证**：记忆召回 100%、组合路由 3 子任务匹配、A2UI Surface 结构
- **论文复现**：SkillWeaver Decompose-Retrieve-Compose（arxiv 2606.18051）忠实复现 + 致谢
- **2 个调研决策**：omm 采纳探索方法（渲染用 A2UI）、book-to-skill/skill-up 归入路线图

**下阶段最高价值**：翻转记忆向量召回开关（P0-1，零代码见效）→ skill-up CI（P0-2，质量保障）→ 路由准确率抽查（P1-3，确认默认开安全）。
