① 阶段脊柱 Stage Spine

消息流左缘的常驻结构：理解 → 计划 → 执行 → 验证 → 交付。一瞥即知"进行到哪、做了什么、花了多少"，整段可折叠成摘要行。这是对 Cursor（编辑器中心）、Codex（任务队列）、Threads（平铺线程）的核心差异化。

② 审批队列

权限请求聚合成一卡，不掐断流；高危项强制逐项确认。替代现状逐 scope 打断式问答与隐晦的 deny 合并逻辑。

③ 五区 Rail

19 个平级按钮收编为 ⌘1–5 五区（工作/变更/资产/知识/系统），区内二级 tab 收纳 11 个面板。按钮永不条件显隐，emoji 图标清零。

④ Inspector 右栏

接通审计发现的断头右栏（P0-1）：跟随焦点对象显示 diff / 权限明细 / 预览，设置改为浮层，主区永不整页替换。

⑤ Command Deck

模式 chips（对话/Plan/自动）+ 上下文迷你环 + 44px 发送键（Fitts 定律）。审批待决时 composer 不再整体禁用。

⑥ StatusBar

新增 22px 常驻状态条：就绪态、分支、进程数、token 总量。进程面板由此进入，替代 ⌘O/⌘J 冗余绑定。
