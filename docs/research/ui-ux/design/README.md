## Demo 交互清单（index.html）

- **范式**：工单即界面——步骤板（点击选中/双击划线/gate 点击切换）、步骤卡（范围 chips 可删、进度流、介入批注、待决内联）
- **模块坞**（左缘居中，v3.2）：全部模块 + 系统入口（通知/记录/主题/设置/文件/变更/进程/资产/审查/知识源/账本/任务树/插件/检查点/编辑器/快捷键/车间墙/新目标），纵向单列、SVG 描边图标 + 文字标签、hover 显快捷键、通知带角标
- **控制中心**（⌘⇧O / 右缘拉手，右缘居中小浮窗；开工后默认展开一次）：只保留观测 + 命令——仪表四宫格（时长/成本/上下文/token）→ 指令输入（地址化选中对象，⌘↵）→ 我的指令（全部用户动作留痕）→ 状态观测（引擎事件流）
- **二级详情页**（列表 → 详情，参考设计资产的不遮挡主区模式）：知识源（每源统计/重建/召回测试/日志）、插件（工具清单/权限/日志/启停/重载）、代码审查（运行历史 → 单次详情）
- **变更抽屉友好版**（v3.2）：分支切换 + ↑↓ 领先落后、暂存区/更改分区、逐文件暂存/移出/还原、拉取/推送（推送走闸门 → 冲突三选项）
- **浮层（全模块，审计全覆盖）**：⌘K 命令层（子序列模糊评分，注册表含全部模块）· ⌘⇧M 车间墙 · ⌘T Tape 记录仪 · ⌘, 设置 · 设计资产库（点卡 → 焦点卡预览）· 代码审查（意见一键转介入）· 知识源仪表盘（重建/召回测试）· Token 账本（按工单归账 + 当前工单实时）· 任务树画布（git-graph，点节点切快照/分叉/回填）· 插件与 MCP（启停）· ⌘⇧Z 检查点恢复 · ⌘? 快捷键表 · 分支冲突三选项（变更抽屉"提交并推送"触发）· ⌘N 新目标工单起草（gate 逐行可改、盖章下发即入车间墙）· 全屏编辑器（只读演示，生产接 Monaco）
- **抽屉**：⌘E 文件（点文件 → 焦点卡 diff）、⌘⇧E 变更、⌘⇧P 进程（实时日志）、⌘⇧N 通知（toast 落档）
- **控制**：自律度三档（⌥1/2/3 或点击旋钮）、⏸ 刹车（Space，冻结/恢复）、⌘. 专注模式
- **引擎模拟**：开工后工单自动施工——进度追加、token/成本/上下文走时、80% 触发压缩观测、高危升起待决、步骤闸门前等待、交付 toast
- **六主题实时切换**（🎨 或 ⌘K 搜主题）：Liquid Glass / Flat / Glassmorphism / Neumorphism / Claymorphism / Vernacular 1997
