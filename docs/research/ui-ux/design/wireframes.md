# Orca Deck v3 设计稿：工单工作台 · 线框与交互规格

> 日期：2026-08-19（v3） · 概念定义见 [[vision]]
> v3 关键变化：**对话降级为记录仪（Tape，⌘T），工单升格为界面本体**。交互从回合制改为并行值守：闸门前置、自律度旋钮、对象锚定的介入、永远可用的刹车。
> 视觉参考稿（浏览器打开）：`index.html`（交互 demo）

---

## 0. 全局 Shell：工作台

```
┌──────────────────────────────────────────────────────────────────┐
│ 目标带 40px（唯一常驻件，兼标题栏）                                  │
│ ●●● ◉ 把权限改成批量审批 ▾   ①━②━◉╌④╌⑤  42s · $0.04 · 62%ctx 🔔³ ⚭│
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│        ┌─────────── 工单区 max 860px 居中 ───────────┐            │
│        │  GOAL 标题 + 约束 chips            [展开 ▾] │            │
│        │  步骤板（横向步骤条）                         │            │
│        │  步骤卡列表（当前步骤展开，其余压缩行）         │   ┌─焦点卡┐│
│        │                                            │   │ 浮动  ││
│        └────────────────────────────────────────────┘   └───────┘│
│        自律度  ━━━●── 关键确认          ⏸ 刹车                     │
│                                                                  │
│        ╭── 指示条（悬浮底部居中）────────────────────────╮          │

│        ╰────────────────────────────────────────────╯          │
└──────────────────────────────────────────────────────────────────┘
```

没有消息流、没有气泡、没有头像。内容列是**工单**。消息流完整保留在 Tape（⌘T，全屏浮层）。

**尺寸**：目标带 40px；工单区 max 860px；步骤板卡片高 44px；步骤卡展开 ≤60% 屏高可滚；指示条宽 min(680px, 92%)；自律度控件位于工单区底部左、刹车在右（拉开防误触）。

## 1. 目标带（Goal Ribbon）

v2 阶段带的升级版，节点从"阶段"改为**工单步骤**（更具体、可数）：

```
◉ 把权限改成批量审批 ▾   ①━━②━━◉╌╌④╌╌⑤   42s · $0.04 · ▓▓▓░62%  🔔³ ⚭
```

- 左：会话名→**目标名**（点击 = 目标切换下拉）。
- 中：步骤节点（完成 实心 / 进行 呼吸脉冲 / 未开始 空心）。点击 = 工单区滚动到该步骤卡；hover = 时长/token/工具数。
- 右：累计时长 · 累计成本（$ 或 token）· 上下文环 · 🔔（待决+通知）· ⚭。
- 无工单时（新目标未下发）退化为 `◉ 新目标 + 🔔 ⚭`。

## 2. 步骤板（Step Board）——工单头部

```
[① 读取权限模块 ✓] [② 设计队列结构 ✓] [③ 改核心 ◉] [④ 验证 ○] [⑤ 交付 ○]
```

- 横排步骤芯片，44px 高，可**拖拽重排**（执行中步骤之后的才可拖），**划线删除**（右键或拖出板外），点击=选中并展开下方步骤卡。
- 每芯片带闸门角标：无标=自动，🛡=执行前确认，✋=完成时确认。高危步骤红点常驻。
- 芯片态即全貌：用户不展开任何卡片也能读懂工单进度。

## 3. 步骤卡（Step Card）——工单主体

当前步骤展开，其余压缩为一行：

```
◉ ③ 改 core 权限策略面                              gate: 自动 ▾   ⏸ 单步停
  范围: [permissions.ts ✕] [session.ts ✕] [+ 添加]
  进度: edit permissions.ts +45 −12 ✓ → typecheck ✓ exit 0 → edit … ◉
  结果: +45 −12 · diff ▸焦点卡 · 原始流 ▸Tape#318
  💬 介入 2 条                                        [展开]
  ⚠ 待决 1 项: git push origin docs/…    [允许] [拒绝] [改为仅提交]
──────────────────────────────────────────────────────────────
✓ ② 设计队列结构 ─ 产出 queue-spec 草案 · 38s · 2.1k tok   [展开]
```

- **范围 chips**：可增删文件/目录，agent 下一步立即受限于此。
- **进度行**：该步骤内的工具调用压缩成一行链（不逐条气泡）；点击任一环节 → 焦点卡。
- **介入**：挂在步骤上的批注列表（见 §4）。
- **待决**：agent 的提问/高危确认内联在此，带选项；不阻塞其他无依赖步骤。
- 压缩行显示一行结构化摘要（零 LLM：文件数/命令数/diffstat/时长/token）。

## 4. 介入机制（Intervention）与指示条

指示条 = v3 的"输入框"，但它是**寻址的**：

```
对 [③ 改 permissions.ts]：高危降级逻辑再保守一点          ⌘↵ 发送介入
```

- 选中什么，指示条就地址什么：步骤卡 / 范围 chip / diff hunk / 目标本身。无选中 = 地址目标。
- 发出后成为对象上的批注 💬，agent 在下一个决策点读取（不等当前工具调用结束）。
- 批注可追加、可划线作废；agent 响应批注时在原批注下回一行（**缩进批注流，不是聊天回合**）。
- 键盘：`⌘↵` 发送；`Tab` 在指示条里循环切换地址（目标→当前步骤→最近对象）。

## 5. 自律度与刹车

```
自律度  ○────●────○   全自动 │ 关键确认 │ 每步确认         ⏸ 刹车
```

- 三档滑杆（键盘 `⌥1/2/3`），工单级默认值；步骤闸门可局部覆盖；**红色高危不受"全自动"覆盖**（安全底线）。
- 它写入权限策略面（替代逐 scope 向导）；当前回合的待决项按新档位立即重算。
- **刹车 ⏸**：64px 宽实体感按钮，任何时候拍下 → 当前工具调用完成后冻结（bash 长任务发 SIGTERM 询问）；工单状态原样保留，再按恢复。生成中指示条的发送键变为 ■ 停止（等价物），双通道冗余。

## 6. Tape（记录仪，⌘T）

```
┌─ Tape · 工单 #3 全量记录 ─────────────────────── ⌘T/Esc 关闭 ─┐
│ 14:02:11  user     把权限改成批量审批（→ 目标）                  │
│ 14:02:14  agent    已起草工单 v1 · 5 步              [对照工单] │
│ 14:02:19  tool     read permissions.ts … 4.1k tok              │
│ 14:03:02  agent    （流式正文…原样保留，含思维链折叠）            │
└────────────────────────────────────────────────────────────────┘
```

现有 MessageList 原样迁入（含吸底/未读/日期分隔这些教科书级实现），加时间戳列与"对照工单"跳转。Tape 是唯一能看到逐字流式正文的地方——主工作台只看结构化状态。

## 7. 车间墙 ⌘⇧M（任务总台的 v3 形态）

卡片 = 工单：目标名 + 步骤迷你条 + 当前步骤一行状态 + 时长/成本 + 待决红点 + 自律度档位标。与 v2 总台同构，内容从"会话"换"工单"。新目标卡 `＋`。

## 8. 焦点卡与抽屉（沿用 v2，对象扩展）

焦点卡触发对象扩展为：步骤进度环节、范围 chip、diff hunk、成本数字、上下文环。四抽屉不变（⌘E 文件 / ⌘⇧E 变更 / ⌘⇧P 进程 / ⌘⇧N 通知）。浮层栈不变：抽屉 < 焦点卡 < Tape < 车间墙/命令层 < 模态。

## 10. 状态灯与措辞规范（去 AI 感的文案层）

- 状态用词表：**待施工 / 施工中 / 待确认 / 已交付 / 已划线 / 受阻**——禁止"思考中""我正在""让我来"。
- 一切进行态必须带量化仪表（N/M 步骤 · 时长 · tok · diffstat），禁止裸动画。
- 机器输出 = 等宽字体块；人 = 常规字体；批注 = 左边条。三种来源零头像区分。

## 11. 降级与兜底

- 步骤与工具流对齐失败 → 事件进"未归类"缓冲条（工单底部灰条），点击展开原始流——永不丢信息。
- 用户可在设置里把默认主视图切回 Tape（聊天心智用户的退路）；v3 工作台与 Tape 共享全部数据，互为视图。

## 12. Onboarding（首开 90 秒）

trust dialog 后落在车间墙（含 1 张示例工单卡）。三步导览：① 工单是会话的新形态——步骤可拖、可划、可设闸门 ② 指示条对"选中的东西"说话 ③ ⏸ 刹车永远在。每步配真实界面标注截图。
