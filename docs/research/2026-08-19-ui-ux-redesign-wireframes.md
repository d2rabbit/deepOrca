# Orca Deck v2 设计稿：无框指挥舱 · 线框与交互规格

> 日期：2026-08-19（v2） · 概念定义见 [[2026-08-19-ui-ux-redesign-vision]]
> v2 关键变化：**移除全部常驻侧栏**（rail / 二级面板 / 右栏 / 状态栏），导航改为召唤式（命令层 ⌘K + 任务总台 ⌘⇧M + 边缘抽屉），阶段脊柱升级为置顶阶段带。
> 视觉参考稿（浏览器打开）：`2026-08-19-ui-ux-redesign-mockup.html`

## 0. 全局 Shell：两个概念，没有网格

```
┌──────────────────────────────────────────────────────────────┐
│ 阶段带 40px（唯一常驻结构件，同时是窗口标题栏）                    │
│ ◉ 会话名 ▾   ●━●━◉╌○╌○   42s · ↓1.2k   62% ctx  🔔  ⚭        │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│              ┌──── 内容列 max 760px 居中 ────┐                │
│              │  消息流（按阶段分组，可整段折叠）  │   ┌─焦点卡─┐ │
│              │                              │   │ 380px │ │
│              │                              │   │ 浮动  │ │
│              └──────────────────────────────┘   └───────┘ │
│                                                              │
│         ╭──────── Command Deck 悬浮底部居中 ────────╮        │
│         │ 输入…                              ▶ │        │
│         ╰──────────────────────────────────────╯        │
└──────────────────────────────────────────────────────────────┘
```

视图状态从 v1 的 `sidebarView × mainView × tabs` 复合状态机简化为两个概念：**内容列 + 浮层栈**。这消灭了审计 P1-2 的"状态组合空格"bug 温床（如 Git 面板"打开编辑器"无反应）。

**尺寸规格**

| 元素 | 尺寸 | 说明 |
|---|---|---|
| 阶段带 | 高 40px | 兼窗口标题栏（红绿灯内联左端） |
| 内容列 | max 760px 居中 | ≈75 字符/行，阅读舒适上限 |
| Command Deck | 宽 min(680px, 92%)，高 min 56px 自适应至 40% 屏高 | 悬浮，距底 16px，圆角 16px |
| 焦点卡 | 宽 380px，高自适应 ≤70% 屏高 | 浮动，锚定选中对象旁 |
| 边缘抽屉 | 宽 320px，全高 | 从缘滑入 ≤200ms，覆盖内容不推挤 |
| 命令层 | 宽 min(640px, 80%) | 全屏遮罩居中偏上 18% |
| 任务总台 | 全屏遮罩 | 卡片 260×160px 网格 |

## 1. 阶段带（Stage Ribbon）

```
┌────────────────────────────────────────────────────────────────┐
│ ●●●  ◉ 重构权限为审批队列 ▾   ①━━②━━◉╌╌④╌╌⑤   42s ↓1.2k  ▓▓▓░ 🔔³ ⚭ │
│                            理解 计划 执行 验证 交付               │
└────────────────────────────────────────────────────────────────┘
```

- **左**：窗口控制 + 会话名（点击 = 快速切换会话下拉，等价于迷你总台）。
- **中**：五阶段节点。状态：完成（实心声呐色）/ 进行中（呼吸脉冲，`prefers-reduced-motion` 时静态高亮）/ 未开始（空心灰虚线）。点击节点 = 消息流定位到该阶段锚点；hover = tooltip（起止时间、token、工具调用数）。`J`/`K` 阶段间跳转。
- **右**：进行时长 + 速率、上下文仪表（迷你环，hover 展开详情）、通知 🔔（未读角标）、设置 ⚭（浮层）。
- 空闲态退化为仅"◉ 会话名 + 🔔 ⚭"，阶段带隐去——chrome 随工作出现，随完成隐去。
- 消息流内的阶段分组头与阶段带节点一一对应，折叠成一行摘要（结构化数据生成，零 LLM 消耗）：`✓ 执行 — 改了 7 个文件 · 3 条命令 · +412/−87 · 96s`。

## 2. 命令层 ⌘K（枢纽）

```
┌─────────────────────── 遮罩 rgba(0,0,0,.45) ───────────────────┐
│        ╭────────────────────────────────────────╮              │
│        │ 🔍 switch to…                          │              │
│        ├────────────────────────────────────────┤              │
│        │ ▸ 会话  修复预览面板 grid 归属     12m前  │              │
│        │ ▸ 视图  任务树画布                       │              │
│        │ ▸ 命令  /pm-design 生成原型              │              │
│        │ ▸ 主题  orca · punk · glass…             │              │
│        │ ▸ 动作  design.drift 品牌漂移检查         │              │
│        ╰────────────────────────────────────────╯              │
└────────────────────────────────────────────────────────────────┘
```

- fzf 风格模糊评分（替换现状 `includes` 子串，`command-palette.tsx:45-51`）；分组展示：会话 / 视图 / 命令 / 主题 / 动作 / 设置项。
- **单一注册表**：slash 菜单、快捷键表、命令层同源——消灭"三个入口三种能力"。
- `>` 前缀锁命令、`@` 锁文件、`#` 锁会话。

## 3. 任务总台 ⌘⇧M（卡片墙）

```
┌──────────────── 遮罩 + 玻璃拟态 ────────────────┐
│   任务总台                              🔍 过滤 │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐        │
│  │◉ 权限队列  │ │✓ 预览修复  │ │◌ 导出.ddp │        │
│  │ ●━●━◉╌○╌○ │ │ ●━●━●━●━● │ │ ●╌○╌○╌○╌○ │        │
│  │ 审批队列卡… │ │ typecheck │ │ 等待输入…  │        │
│  │ 42s·🔴3待决│ │ ✓ 12m前    │ │ 2h前      │        │
│  └──────────┘ └──────────┘ └──────────┘        │
│              [+ 新会话 ⌘N]                      │
└─────────────────────────────────────────────────┘
```

卡片 = 会话名 + 迷你阶段带 + 最新一行输出 + 时长/token + 待决红点。这是多会话的总览层，也是新用户的 onboarding 首屏。

## 4. 边缘抽屉（瞬时一瞥）

```
┌──────────────────────────────────────────┐
│▏文件树（左抽屉，⌘E 或左缘悬停滑出）         │
│▏▾ packages/desktop/src/renderer          │
│▏  ▸ App.tsx          ● modified          │
│▏  ▸ Composer.tsx                         │
└──────────────────────────────────────────┘
```

- 四个抽屉：左=文件树 ⌘E、左=变更 ⌘⇧E（git）、右=进程输出 ⌘⇧P、右=通知 ⌘⇧N。
- **覆盖而非推挤**内容列；失焦/Esc 即收；右上角"📌 钉住"后转为持久浮动窗（可拖、多开）。
- 抽屉内点击文件 → 焦点卡显示 diff，内容列不被替换。

## 5. 焦点卡（Focus Card）

```
                内容列
   ┌──────────────┐
   │ ▸ 🔧 edit permissions.ts +45 −12 │╌╌╌┐
   └──────────────┘                  ▼ 锚定
                          ╭── permissions.ts 的变更 ─── 📌 ✕ ─╮
                          │ @@ -106,7 +106,7 @@               │
                          │ -  const risk = "high"            │
                          │ +  const risk = queueable(...)    │
                          │ [在编辑器打开] [还原此文件]          │
                          ╰────────────────────────────────────╯
```

- 触发：点击消息流中任何可检视对象（文件卡、权限项、token 计、设计产物、阶段节点）。
- 380px 浮动卡，锚定对象旁（Quick Look 心智）；可拖动；📌 钉住后持久化（可多张并存）；Esc 关闭最上层。
- 技术承接：即修复审计 P0-1 的替代方案——不再需要"右栏 dock"，`.ui-rightpanel`/`.ui-shell.right-open` 死代码直接删除，预览/diff 统一走 FocusCard 组件（归 OverlayStack 管理）。

## 6. 审批队列（保留主张，位置不变）

消息流内联卡片，一轮所有待决项聚合：

```
╭ 审批队列 · 3 项待决 ──── 不阻塞：agent 正在继续无风险步骤 ─╮
│ 🟡 写 permissions.ts                              [允许] │
│ 🟢 读 docs/permission.md                            [允许] │
│ 🔴 git push origin docs/…                  [允许] [拒绝] │ ← 高危强制逐项
│ [全部允许本轮（高危除外）]        [逐项 ▸ 焦点卡检视]        │
╰──────────────────────────────────────────────────────────╯
```

deny 后项上显示"已拒绝"胶囊（取代隐晦的 `pendingPermissionReply` 合并）；待决数同步进阶段带 🔔 角标与任务总台卡片。

## 7. Command Deck（输入台）

```
╭──────────────────────────────────────────────────────────────╮
│ [对话▾] [⬡Plan] [@3文件]                                       │
│ 输入消息…（/ 命令 · @ 文件 · 拖图）                              │
│ ◔62%   ✨flash 改写                                   ▶ 发送 ⌘↵ │
╰──────────────────────────────────────────────────────────────╯
```

- 模式 chips 取代 Shift+Tab 隐式切换；上下文迷你环在左下；发送键 44×44 右下固定，生成中变 ■ 停止。
- 审批待决时 composer **不再禁用**（修 P1-5 打断性），placeholder 提示"3 项审批待决"。

## 8. 任务树画布（浮层化）

从"会话徽章才能进的主区 tab"（P1-3）改为 ⌘K/抽屉可达的**全屏浮层画布**：git-graph 节点=任务快照，hover 显 why 备注，点击切快照；横向平移缩放，右下角迷你地图。Esc 回消息流。

## 9. 键盘地图（v2 全量）

| 键 | 动作 | 键 | 动作 |
|---|---|---|---|
| ⌘K | 命令层 | ⌘⇧M | 任务总台 |
| ⌘E / ⌘⇧E | 文件 / 变更抽屉 | ⌘⇧P / ⌘⇧N | 进程 / 通知抽屉 |
| ⌘I | 钉住焦点卡 | ⌘N | 新会话 |
| ⌘, | 设置浮层 | ⌘. | 专注模式（隐阶段带） |
| Esc | 关最上层浮层 / 停止生成 | ⌘⇧Esc | 关闭全部浮层 |
| J / K | 阶段间跳转 | ↑/↓ | 历史 prompt |
| ⌘↵ | 发送 | 1–9 | 问答卡快捷选择 |

移除 ⌘O/⌘J 冗余（修 P2-2）；无 ⌘1–5——v2 没有"区"可切。

## 10. 浮层栈（v2 架构支柱）

一切皆浮层，栈序即 z 序：抽屉 < 焦点卡 < 设置 < 命令层/总台 < 模态（trust/冲突）。Esc 弹栈顶、⌘⇧Esc 清空、背景点击仅弹非模态栈顶。迁移顺序：OverlayStack 基座 → CommandPalette → FocusCard（新）→ Settings → UndoModal/ShortcutsModal/DiffOverlay → 四抽屉 → 任务总台。PrototypeWindow 独立窗口除外。

## 11. 设计 Token 增补

```
--ui-sonar:              声呐强调色（orca = #4DE3C2；各主题各自定义）
--ui-ribbon-active:      阶段带脉冲色
--ui-stage-done / -todo
--ui-scrim:              浮层遮罩 rgba（各主题明暗两套）
--ui-glass-bg/-border:   浮层玻璃拟态
--ui-risk-low/-mid/-high（沿用权限三色，推广全局）
--ui-density-space:      0.875 / 1 / 1.125
--ui-font-base:          14px（随密度缩放）
--ui-motion-slide:       200ms（reduced-motion 置 0）
```

新组件只消费 token；emoji、硬编码色值、写死的 13.5px 随迁移清零。

## 12. Onboarding（首开 90 秒）

trust dialog 后直接落在**任务总台**（空态即教程）：3 张示例卡教三件事——① ⌘K 是万能入口 ② 阶段带告诉你 agent 进行到哪 ③ 左缘滑出文件、右缘滑出进程。可跳过，通知中心可重开。
