① 工单即界面

屏幕主体是正在被建造的东西：目标、约束、步骤板、步骤卡。对话降级为 ⌘T 记录仪。工件即界面，对话是脚注——这是与一切"聊天壳"产品的本体差异。

② 步骤是可操作对象

步骤芯片可拖拽重排、划线删除、改范围 chips、逐步设闸门（自动/执行前确认/完成时确认）。你改的不是对话，是正在进行的工作本身。

③ 并行值守，回合制消亡

闸门前置取代中途弹卡；agent 的提问挂在步骤上不阻塞其他步骤；你半小时后回来一次答完，它按新状态继续——而不是干等。

④ 自律度旋钮 + 刹车

三档物理控件（全自动/关键确认/每步确认）取代逐条审问；高危项不受全自动覆盖。⏸ 刹车永远可用，拍下即冻结、再按恢复。

⑤ 介入，而非对话

指示条永远标注"对 [选中对象] 说"。批注挂在步骤/文件/hunk 上，像 code review 的 inline comment，不像微信。

⑥ 仪器化，去拟人

无气泡、无头像、无"思考中"。进行态必须带量化仪表（N/M 步 · 时长 · $ · diffstat）；机器输出用等宽字体，人用常规字体，来源靠排印区分。
