① 阶段带 Stage Ribbon

窗口唯一常驻结构件（40px，兼标题栏）：会话名 + 五阶段进度 + 上下文仪表 + 通知。空闲时隐去，工作启动才"亮"。回答竞品回答不了的"进行到哪一步"。

② 零常驻侧栏

v1 的 rail/二级面板/右栏/状态栏全部移除——不再有 VS Code 式地契。屏幕不再为"可能用到"付费，内容列是唯一主角。

③ 召唤式导航

⌘K 命令层（真模糊、全覆盖）管动词，⌘⇧M 任务总台管名词，边缘抽屉（⌘E 文件 / ⌘⇧P 进程）管一瞥——用完即收，可钉住。

④ 焦点卡 Focus Card

Quick Look 心智取代右栏 dock：点消息里的对象，380px 玻璃卡锚定在旁。可拖动、可钉住多张。同时消化了审计发现的断头右栏死代码。

⑤ 审批队列

一轮权限请求聚合为一卡，流不掐断；高危项强制逐项；deny 以可见胶囊呈现。待决数同步进阶段带 🔔 与总台卡片。

⑥ 浮层栈架构

一切皆浮层，栈序即 z 序；Esc 关最上层、⌘⇧Esc 全关。视图状态从 sidebarView×mainView 复合状态机简化为「内容列 + 浮层栈」，消灭状态组合 bug 温床。
