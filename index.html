✦ 快速开始

三步部署，即刻创作

需要 Node.js 22+ 与 npm 10.9+；Windows 上 bash 工具需要 Git Bash。

01

获取应用

克隆仓库并安装依赖，一条命令构建并启动桌面客户端。

# clone & install
git clone https://github.com/d2rabbit/deepOrca.git
cd deepOrca && npm install
# build & run desktop client
npm run desktop:start
02

接入模型

创建 ~/.deeporca/settings.json（已有 ~/.deepcode 配置会直接沿用，无需迁移）。

{
  "env": {
    "MODEL": "deepseek-v4-pro",
    "BASE_URL": "https://api.deepseek.com",
    "API_KEY": "sk-..."
  },
  "thinkingEnabled": true,
  "reasoningEffort": "max"
}
03

开始创作

描述你的需求 —— 原型、设计稿、代码，虎鲸接手剩下的工作。

# try in the composer
"帮我搭一个看板管理原型"
"出一个玻璃拟态的落地页设计稿"
✦

开启你的创作之旅
