⚡ Actions：能力一次定义，多处调用

单个 defineAction 定义自动成为 LLM 工具、桌面 IPC/UI 与组合工作流 —— 内置代码审查、知识索引、系统诊断等 Actions 开箱即用。

defineAction → LLM Tool → Desktop UI → 组合工作流 
// 一次定义，自动多表面
defineAction({
  name: "code.review",
  schema: z.object({ path: z.string() }),
  run: (input) => crg.review(input.path),
});

// 快速开始

三步部署，即刻创作

需要 Node.js 22+ 与 npm 10.9+；Windows 上 bash 工具需要 Git Bash。

01

获取应用

克隆仓库并安装依赖，一条命令构建并启动桌面客户端。

# clone & install
git clone https://github.com/d2rabbit/deepOrca.git
cd deepOrca && npm install
# build & run desktop client
npm run desktop:start
02

接入模型

创建 ~/.deeporca/settings.json（已有 ~/.deepcode 配置会直接沿用，无需迁移）。

{
  "env": {
    "MODEL": "deepseek-v4-pro",
    "BASE_URL": "https://api.deepseek.com",
    "API_KEY": "sk-..."
  },
  "thinkingEnabled": true,
  "reasoningEffort": "max"
}
03

开始创作

描述你的需求 —— 原型、设计稿、代码，虎鲸接手剩下的工作。

# try in the composer
"帮我搭一个看板管理原型"
"出一个玻璃拟态的落地页设计稿"

开启你的创作之旅
