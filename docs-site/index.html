// 03

启动序列

三步部署，即刻潜航

STEP
01

获取应用

从 GitHub Releases 下载对应平台安装包，或从源码构建：

$ git clone https://github.com/d2rabbit/deepOrca.git
$ cd deepOrca && npm install
$ npm run desktop:start
STEP
02

接入模型

在应用「设置」面板填写模型信息，或编辑 ~/.deeporca/settings.json：

{
  "env": {
    "MODEL": "deepseek-v4-pro",
    "BASE_URL": "https://api.deepseek.com",
    "API_KEY": "sk-..."
  },
  "thinkingEnabled": true,
  "reasoningEffort": "max"
}
STEP
03

开始围猎

打开 DeepOrca，选择项目文件夹，输入需求 — 虎鲸出击，与 AI 结对编程。
