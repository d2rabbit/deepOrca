# Macrostructure: Landing Flow

> Page skeleton fingerprint — visual system agnostic. This is the classic
> conversion funnel skeleton — listed LAST among the ten because it is the
> default slop shape: picking it requires saying why none of the other nine
> fit.

## Skeleton fingerprint

- **Title placement**: classic hero — eyebrow, display headline, one lead
  sentence, ONE primary CTA (+ one text link); hero occupies the first
  viewport and ends there.
- **Separation language**: alternating section bands (visual / text, text /
  visual) separated by full-width section padding; each band uses ONE idea.
- **Button voice**: primary CTA repeats at most 3 times down the page (hero,
  mid social proof, final CTA band), identical component every time.
- **Image handling**: one product shot per band, alternating sides; logos row
  for social proof is grayscale and small.
- **Reveal**: one entrance animation per band on scroll-in, same duration and
  easing every time; the repetition IS the rhythm.

## Layout math

- 5-8 bands max: hero → social proof → feature A → feature B → objection/
  FAQ → final CTA → footer. Bands share one container width and one vertical
  padding; feature bands mirror media side (left/right) between neighbors.

## Use when

Product marketing pages where the goal is a single conversion. If the page
has two different goals, it is two pages.

## Do not

- more than 8 bands (attention dies; cut content instead);
- different CTA copy/components at different positions;
- a stats row without a source or timeframe — fake precision is slop.
