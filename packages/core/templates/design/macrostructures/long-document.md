# Macrostructure: Long Document

> Page skeleton fingerprint — visual system agnostic.

## Skeleton fingerprint

- **Title placement**: full-width H1 with a standfirst (2-3 line lede), then
  continuous single-column flow. The document starts above the fold; no hero.
- **Separation language**: whitespace + subheads only — no cards, no boxes
  inside the body; hr is allowed once per major part.
- **Button voice**: none in the flow; actions live in a sticky toolbar or the
  footer. Links are inline text, never buttons.
- **Image handling**: sparing, full column width, always captioned; one image
  per 3-5 paragraphs maximum.
- **Reveal**: nothing animates in the reading flow; a reading-progress bar is
  the only motion allowed.

## Layout math

- One measure: body column 60-72ch, fixed; wider screens grow margins, never
  the measure. Side elements (TOC, margin notes) float outside the measure.
- Vertical rhythm driven by one line-height multiple for the whole document.

## Use when

Essays, docs, policies, changelogs, long-form journalism, terms. If the
content is meant to be read top-to-bottom, it is a Long Document — do not
card-ify it.

## Do not

- Cards, tiles, or multi-column body text;
- parallax or scroll-triggered section animations;
- breaking the measure for a pull-quote (pull-quotes may intrude into margin
  space, not across the measure).
