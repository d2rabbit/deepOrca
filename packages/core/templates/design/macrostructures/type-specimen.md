# Macrostructure: Type Specimen

> Page skeleton fingerprint — visual system agnostic.

## Skeleton fingerprint

- **Title placement**: the typeface name AS the artwork — set in the face
  itself, oversized, usually cropped by the viewport edge.
- **Separation language**: baseline rules, registration marks, or annotated
  measurements; separation is typographic furniture, never cards.
- **Button voice**: minimal — a "get/license" link in a corner toolbar;
  interactions are the specimens themselves (editable sample text, sliders).
- **Image handling**: glyphs ARE the images; if photography appears it is one
  duotone block demonstrating the face over image.
- **Reveal**: static specimen rows; weight/style axes may animate once on
  scroll into view (interpolation demos), no other motion.

## Layout math

- Specimen rows at 3 fixed sizes (display / text / caption) each showing the
  same pangram or user-editable line; annotations in mono at caption size.
- Wide asymmetry: 80% specimen column, 20% metadata gutter.

## Use when

Font marketing, typography portfolios, brand identity reveals, and as a
rhetorical device for any "the medium is the message" page. Also the safest
skeleton when the brief is literally "make type the hero".

## Do not

- more than two typefaces on the page (the specimen + the annotation face);
- boxes around specimen rows;
- filling silence with icons — a specimen page is allowed to be stark.
