# Design System: Editorial

> Magazine-grade — serif headlines, strong contrast, structured grid.

## Color

- Background: `#fdfcf8` (warm white)
- Surface: `#f4f0e8` (parchment)
- Accent: `#8b0000` (dark red — max 2 uses per screen)
- Text: `#1c1c1c`
- Muted: `#6b6b6b`

## Typography

- Display: serif (Playfair Display / Georgia), weight 700, tight tracking
- Body: serif (Charter / Georgia), weight 400, relaxed line-height (1.7)
- Mono: monospace (Courier Prime / monospace)
- Eyebrows/labels: mono, uppercase, wide tracking

## Layout

- Max-width: 860px (narrow reading column)
- Section padding: 64px vertical
- Grid: 6-column, 20px gap
- Card radius: 0 (sharp edges — editorial style)
- Button radius: 0

## Motion

- Transitions: none (static, print-like)
- Hover: underline reveal on links only

## Components

- Button primary: accent background, white text, uppercase, letter-spacing 0.05em
- Button ghost: transparent, 2px solid border (text color)
- Card: surface background, no border, 1px top rule
- Image placeholder: parchment gray, framed with 1px border
- Section dividers: horizontal rule (1px solid text-color at 15% opacity)
