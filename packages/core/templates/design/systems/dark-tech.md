# Design System: Dark Tech

> Default system for DeepOrca — dark, neon-accented, compact.
> Matches the Orca product aesthetic.

## Color

- Background: `#0a0a0a`
- Surface: `#141414`
- Accent: `#6366f1` (indigo — max 2 uses per screen)
- Text: `#fafafa`
- Muted: `#737373`

## Typography

- Display: serif (Iowan Old Style / Charter / Georgia)
- Body: sans-serif (system-ui / -apple-system)
- Mono: monospace (SF Mono / Fira Code)
- Numerics, captions, eyebrows: mono

## Layout

- Max-width: 1200px
- Section padding: 80px vertical (48px on mobile)
- Grid: 12-column, 24px gap
- Card radius: 12px
- Button radius: 8px

## Motion

- Transitions: 200ms ease
- Hover lift: translateY(-2px) on buttons
- Card hover: border brightens to accent

## Components

- Button primary: accent background, white text, 12px/24px padding
- Button ghost: transparent, muted border, hover reveals text color
- Card: surface background, subtle border, 32px padding, hover accent border
- Image placeholder: muted background, no external URLs
